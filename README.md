### 🚀 About Me

I didn't write a line of code until university. It seems strange but I went through a traditional Liceo Scientifico, with no computer science in the curriculum and my first real contact with programming came when I started my degree.  
 Since then I've been catching up fast, working through OOP, algorithms, SOLID principles, Clean Code, Design patterns, MVC architecture, and building my own projects along the way.  
Late start, but somehow it's worked out very well so far, always with great results. Still hungry to learn more and get better every day!

🔭 &nbsp;I'm currently working on **functional programming**  
🌱 &nbsp;I'm currently learning **software engineering**
